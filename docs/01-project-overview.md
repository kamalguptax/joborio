# Project Overview

## Product

**Creator Performance Marketplace** (JobOrio platform) — career & education, all niches, global. Creators share one link; jobs/courses auto-match to niche/geo; earnings in **USD** only.

## Problems solved (blueprint §2)

- **Creators:** One link, auto inventory, dashboard, payouts — no brand deals or employer contact.
- **Employers/institutes:** Self-serve programs, pay on performance, niche reach, **blind matching** (no creator identity).
- **Platform:** ~25–30% take rate; tracking + trust + payout as moat.

## Users

| Role | Account | Primary value |
|------|---------|----------------|
| Creator | Yes | Handle, public page, dashboard, payouts |
| Job seeker / student | No (public) | Browse/apply via creator page |
| Employer / institute | Yes | Programs, budget, anonymized stats |
| Admin | Yes | Fraud, payouts, CMS, global ops |

## Success metrics (blueprint §11)

500+ active creators (M6), >40% creator-to-active, 200k verified clicks/mo, <8% fraud rate, $30+ avg creator earnings/mo, >99% payout success, etc.
